# AlbaPayGuard

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
출퇴근 기록만으로 주휴수당까지 포함한 정확한 알바 급여를 자동 계산하고 미지급 여부를 체크해주는 앱

## Problem
다수 알바생이 주휴수당 지급 조건(주 15시간 이상 등)을 몰라 정당한 급여를 받지 못하거나 실제 지급 명세서 검증이 어려움

## Target Users
대학생·청년 아르바이트생, 단기·시간제 근로자

## Core Features
1. 출퇴근 시간 일일 기록
2. 시급 기반 주휴수당 자동 계산
3. 야간·연장·휴일수당 가산 계산
4. 월 예상 급여 실시간 누적
5. 최저임금 위반 여부 경고
6. 실제 지급액과 비교한 미지급분 분석 리워드 광고 게이팅

## Monetization
- Model: ads
- Estimated MRR: ₩386,000/월 (약 $286)
- Reasoning: 매일 출퇴근 기록 습관을 통해 배너 노출을 확보하고, 미지급 분석 리포트를 리워드 광고로 게이팅해 전환율 확보
